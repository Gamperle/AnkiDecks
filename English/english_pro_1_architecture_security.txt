Rückverfolgbarkeit / Tracing	distributed tracing
Beobachtbarkeit	observability
Telemetrie	telemetry
Korrelations-ID	correlation ID
Ablaufverfolgung / Span	span (tracing)
Lastabwurf / Load Shedding	load shedding

Befehl / Command (CQRS)	command (CQRS)
Abfrage / Query (CQRS)	query (CQRS)

Konsensalgorithmus	consensus algorithm
Leiterwahl / Leader Election	leader election
Verteilte Sperre	distributed lock

Active-Active-Konfiguration	active-active configuration
Active-Passive-Konfiguration	active-passive configuration
